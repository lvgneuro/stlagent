Горячие клавиши OpenCode
========================

LEADER KEY
----------
По умолчанию Ctrl+X — лидер-клавиша. Сначала нажимаете её, потом действие
(например, Ctrl+X + n = новая сессия).


ОСНОВНЫЕ
--------
Ctrl+K              Поиск
Ctrl+C + Ctrl+D     Выход
<leader>Q           Выход (после лидер-клавиши)
<leader>E           Открыть редактор
<leader>T           Список тем
<leader>B           Переключить сайдбар
<leader>S           Статус
<leader>X           Экспорт сессии
<leader>N           Новая сессия
<leader>L           Список сессий
<leader>G           Таймлайн сессии
<leader>R           Переименовать сессию
Ctrl+R              Переименовать сессию
Escape              Прервать выполнение
<leader>C           Компактный режим


НАВИГАЦИЯ ПО СООБЩЕНИЯМ
-----------------------
PageUp / Ctrl+Alt+B      Страница вверх
PageDown / Ctrl+Alt+F    Страница вниз
Ctrl+Alt+Y               Строка вверх
Ctrl+Alt+E               Строка вниз
Ctrl+G / Home            Первое сообщение
Ctrl+Alt+G / End         Последнее сообщение
<leader>Y                Копировать
<leader>U                Отменить
<leader>R                Повторить


МОДЕЛИ И АГЕНТЫ
---------------
<leader>M          Список моделей
F2                 Цикл недавних моделей
Shift+F2           Цикл недавних моделей (обратно)
Ctrl+P             Список команд
<leader>A          Список агентов
Tab                Цикл агентов
Shift+Tab          Цикл агентов (обратно)
Ctrl+T             Цикл вариантов


ВВОД ТЕКСТА
-----------
Ctrl+A                   Начало строки
Ctrl+E                   Конец строки
Ctrl+B / Left            Назад на символ
Ctrl+F / Right           Вперёд на символ
Alt+B / Ctrl+Left        Назад на слово
Alt+F / Ctrl+Right       Вперёд на слово
Ctrl+D / Delete          Удалить символ
Ctrl+K                   Удалить до конца строки
Ctrl+U                   Удалить до начала строки
Ctrl+W / Ctrl+Backspace  Удалить предыдущее слово
Alt+D / Ctrl+Delete      Удалить следующее слово
Ctrl+T                   Транспонировать символы
Ctrl+Z                   Отменить
Ctrl+. / Ctrl+Shift+Z    Повторить
Return                   Отправить
Shift+Return             Новая строка
Ctrl+G                   Отмена / прервать


НАВИГАЦИЯ ПО СЕССИЯМ (SUBAGENT)
-------------------------------
<leader>Down   К первому дочернему
Right          Цикл по дочерним
Left           Цикл по дочерним (обратно)
Up             К родителю


ПРИМЕЧАНИЯ
----------
- <leader> = лидер-клавиша (по умолчанию Ctrl+X)
- Полный список и настройка в tui.json → раздел keybinds
